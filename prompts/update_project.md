현재까지의 작업 내용과 변경사항을 분석해서
기존 Markdown 문서를 최신 상태로 업데이트해줘.

업데이트 대상:

* PROJECT.md
* STATUS.md
* HANDOFF.md
* README.md

업데이트 목적:

* 새로운 AI 또는 새로운 대화창에서도 바로 작업 가능하도록 유지
* 현재 프로젝트 상태를 문서만으로 이해 가능하게 유지
* 긴 대화 기록 없이도 컨텍스트가 이어지도록 유지

업데이트 규칙:

1. PROJECT.md

* 구조나 기술스택이 바뀐 경우만 수정
* 불필요한 재작성 금지
* 핵심 구조 유지

2. STATUS.md

* 완료된 작업 반영
* 현재 작업 상태 갱신
* 다음 작업 목록 업데이트
* 해결된 문제 제거 또는 완료 처리

3. HANDOFF.md

* 다음 세션 기준으로 완전히 최신 상태 유지
* 현재 가장 중요한 작업 우선 작성
* 지금 막 작업 중인 내용 반영
* 다음 작업자가 바로 이어서 작업 가능하게 작성

4. README.md

* 실행 방법 또는 설치 구조가 변경된 경우만 수정

공통 규칙:

* 문서를 불필요하게 길게 만들지 말 것
* 이전 내용과 중복 제거
* 핵심 컨텍스트 유지
* 실제 현재 상태 기준으로 업데이트
* 사람이 읽어도 이해 가능해야 함
* 어떤 AI라도 읽고 이어서 작업 가능해야 함

마지막에는:

* 이번 세션에서 변경된 핵심 사항
* 다음 세션 우선 작업
* 현재 가장 위험하거나 불안정한 부분

을 요약해서 정리해줘.
